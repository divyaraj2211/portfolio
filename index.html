Campus Q

An in-house QR attendance system that replaced paper registers and manual check-in at Manipal University Jaipur's large events.

4,200+students
~5,400QR scans
<3sper gate scan
0downtime
INIZIO 2026B.Tech freshers' event · ~3,000 students · single-gate flow
CDOE Convocation 2026~1,200 graduates · gate + classroom dual scan
  • Bulk Excel upload generates a unique QR pass per student and emails it automatically through Microsoft 365, so nothing is printed by hand.
  • Gate scans validate the student and block re-entry with atomic database updates, in under 3 seconds each.
  • Dual-checkpoint flow for convocation: a student counts as fully attended only after both the gate scan and a seat scan in their assigned room.
  • Room lock stops a student being scanned in the wrong classroom.
  • Role-based access for security, coordinators, admins and superadmins, with a live dashboard showing entries, room fill and absentees.
  • Deployed it to the public internet myself on a Microsoft Azure VM, with nginx as an SSL reverse proxy and the app running as an auto-restarting Windows service.
